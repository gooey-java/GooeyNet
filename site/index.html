GooeyNet

Send messages between classmates’ computers and build apps that talk to each other.

GooeyNet is still brewing. When it’s ready, your programs will talk to each other through a class server, with no sockets to set up.

Follow along on GitHub See the other libraries

What’s brewing

  • Chat apps and multiplayer games

    Send messages from one program to another, so the whole class can talk or play together.

  • Runs through a class server

    Every program connects to one server for the class, and the server passes messages along.

  • No sockets to set up

    Send and receive messages with simple method calls. GooeyNet handles the networking.

GooeyNet is free and open source under the MIT License. Read the code on GitHub.
